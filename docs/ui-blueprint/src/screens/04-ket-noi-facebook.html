Các nền tảng khác kết nối thế nào

YouTube
Đăng nhập Google → chọn kênh → MateLive tự tạo phiên, lấy key, đọc & trả lời chat qua API.
TikTok Shop
Tài khoản phải đủ điều kiện LIVE. Lấy Server URL + key trong LIVE Studio / Seller Center, dán vào mỗi phiên. Không có API bình luận chính thức.
Shopee Live
Seller Centre → Shopee Live → tạo phiên, chọn phát bằng OBS → dán RTMP URL + key. API Livestream của Shopee chưa mở cho Việt Nam.
Chỉ tài khoản chính chủ hoặc được ủy quyền. MateLive không nhận đăng nhập bằng mật khẩu, không hỗ trợ "ních ảo" hay tài khoản dùng để tự bình luận — các nền tảng coi đó là tương tác giả và có thể khóa luôn tài khoản shop thật.
